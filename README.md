# Brewline Roasters ☕

A responsive specialty coffee roastery website built for **Brewline Roasters**, a fictional local coffee brand. The website provides customers with information about the roastery, its coffee products, and contact details, along with an interactive shopping cart experience.

---

## 📌 Project Overview

**Brewline Roasters** is a multi-page responsive website designed to represent a modern local coffee roastery.

The project focuses on:

- Responsive web design
- Semantic HTML5
- CSS Flexbox and Grid
- JavaScript interactivity
- Product browsing and filtering
- Shopping cart functionality
- Contact form validation
- Accessible and user-friendly navigation
- Mobile-first responsive behavior

The website is designed to work across desktop, tablet, and mobile screen sizes.

---

## ✨ Features

### 🏠 Home Page

The home page introduces Brewline Roasters and provides an overview of the brand.

Features include:

- Hero section
- Coffee-focused imagery
- Introduction to Brewline Roasters
- Featured coffee products
- Product highlights
- Call-to-action sections
- Responsive navigation
- Consistent footer

### 🔎 Product Category Filtering

JavaScript is used to allow users to filter products by category.

This makes it easier for users to browse specific types of coffee and products.

---

### 🛒 Shopping Cart

The project includes an additional shopping cart feature.

Users can:

- Add products to the cart
- View cart items
- Increase product quantity
- Decrease product quantity
- Remove products
- View item quantities
- View subtotal
- View shipping cost
- View total price
- See the cart item count in the navigation

Cart data is stored using the browser's **Local Storage**, allowing cart information to remain available when the page is refreshed.
